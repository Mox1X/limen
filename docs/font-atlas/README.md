# Шрифтовой атлас и плотность ASCII

Шрифт: JetBrains Mono Regular v2.304, 16 px/em. Печатные ASCII U+0020–U+007E, всего 95 символов. Сгенерированная ячейка 10×22, baseline 17, начало X = 0. Максимальная плотность `@` равна 0.23395723; точки, линии и буквы сохраняют свою фактическую долю покрытия.

Артефакты:

- [Растровый атлас PGM](font/atlas.pgm): 16 ячеек в строке, порядок ASCII, между ячейками по одному пустому пикселю. PGM открывается графическим редактором с поддержкой Netpbm; это не формат браузерного preview.
- [Метаданные и порядок символов по плотности](font/atlas-info.txt).
- [Плотности и восемь значений каждой маски](font/densities.tsv), порядок отсчётов по строкам, слева направо.
- Освещение: [встроенный brightness](builtin/brightness.txt), [встроенный shape](builtin/shape.txt), [шрифтовой brightness](font/brightness.txt), [шрифтовой shape](font/shape.txt).
- Силуэт: [встроенный brightness](builtin/brightness-silhouette.txt), [встроенный shape](builtin/shape-silhouette.txt), [шрифтовой brightness](font/brightness-silhouette.txt), [шрифтовой shape](font/shape-silhouette.txt).
- Одинаковые синтетические входы: [встроенный подбор](builtin/synthetic.txt), [шрифтовой подбор](font/synthetic.txt).

Череп: локальный `Skull.obj`, объект `part_0`, X = 180°, 120×40 символов, sampling 2×4, cell aspect = 0.5, неподвижный боковой свет, contrast 1.2, gamma 1. Снимки фиксируют исходный ракурс без строки статуса. Шрифтовая калибровка изменяет обе ветки: brightness подбирает из 95 измеренных плотностей, shape — из реальных масок.

Подбор по реальному шрифту не гарантирует лучшую читаемость анатомии. На текущем черепе возникают более разнообразные буквенные полутона, а shape местами предпочитает повторяющиеся скобки. Сетка 2×4 теряет часть различий между глифами. Результат зависит также от совпадения файла/начертания, размера, ячейки и сглаживания с реальным терминалом. Это основание для дальнейших сравнений, а не утверждение о безусловном улучшении картинки.

## Измерения

Локальный Linux, Rust 1.98.0, release; 31 016 невырожденных треугольников. По 300 вращающихся кадров для полного рендера и 300 повторений преобразования готового framebuffer исходного ракурса. Чтение шрифта, построение атласа, экспорт и терминальный I/O в стоимость кадра не входят.

| Атлас / алгоритм | Полный кадр, мс | Преобразование, мс |
| --- | ---: | ---: |
| Встроенный / brightness | 8.671 | 0.082 |
| Встроенный / shape | 9.016 | 0.323 |
| Шрифтовой / brightness | 9.058 | 0.164 |
| Шрифтовой / shape | 9.495 | 0.631 |

Однократное чтение шрифта и построение атласа заняло 6.365 мс. Шрифтовой shape добавил около 0.31 мс к преобразованию по сравнению со встроенным shape; полный CPU-кадр остаётся в бюджете 33.3 мс для 30 FPS в этом окружении. Результаты зависят от нагрузки системы и терминального вывода.

## Воспроизведение

```sh
cargo run --release --example benchmark -- Skull.obj --object part_0 --rotate-x 180 \
  --compare-glyphs --snapshot-dir docs/font-atlas/builtin

cargo run --release --example benchmark -- Skull.obj --object part_0 --rotate-x 180 \
  --compare-glyphs --font tests/fixtures/fonts/JetBrainsMono-Regular.ttf \
  --font-size 16 --snapshot-dir docs/font-atlas/font

cargo run --release -- Skull.obj --object part_0 --rotate-x 180 \
  --font tests/fixtures/fonts/JetBrainsMono-Regular.ttf --font-size 16 --glyph-mode shape
```

Для явной ячейки добавьте `--font-cell 10x22`. Для независимого изменения пропорций проекции используйте `--cell-aspect`. В просмотрщике нажмите Space для фиксации ракурса, затем `M` для сравнения алгоритмов внутри одного атласа. Выбор встроенного/шрифтового атласа производится при запуске.

Тестовый шрифт и его источник описаны в [fixtures/fonts](../../tests/fixtures/fonts/README.md); OFL прилагается. Модель черепа остаётся локальной и исключена из Git.

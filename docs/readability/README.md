# Читаемость черепа: контрольное сравнение

Снимки созданы на локальном `Skull.obj`, объект `part_0`, поворот X = 180°, 120×40 символов изображения, 2×4 отсчёта на символ, cell aspect = 0.5. Это фиксированный ракурс; нижняя строка статуса приложения в снимки не включена.

- [До](before.txt): камера `(0, 0, 3.5)`, прежний свет `normalize(-0.5, 0.8, 1)`, ambient 0.12, линейная ASCII-шкала.
- [После](after.txt): автоматическое вписывание, zoom 1, свет с азимутом −55° и высотой 35°, ambient 0.06, contrast 1.2, gamma 1.
- [Глубина](depth.txt), [силуэт](silhouette.txt), [нормали X](normal-x.txt), [Y](normal-y.txt), [Z](normal-z.txt).

Оба пресета отрисованы текущим конвейером; `before` воспроизводит прежние визуальные настройки. Точный исходный код предыдущей версии сохранён первым коммитом репозитория. Файлы TXT содержат только ASCII-кадр, включая поля; открывайте моноширинным шрифтом без переноса строк.

В новом варианте череп занимает большую часть кадра. Боковой свет и контраст сильнее отделяют глазницы, носовую область и зубы от освещённой поверхности. Правая сторона темнее; стрелки позволяют проверить противоположное направление света. Потерянная при выборе символа мелкая геометрия не восстанавливается настройкой яркости: для неё нужны больше терминальных ячеек или zoom. Геометрия, нормали OBJ и число символов шкалы не менялись.

## Измерения

Контрольный запуск 2026-10-20, локальный Linux, Rust 1.98.0, release, 300 кадров на вариант. Камера/свет/ASCII-параметры соответствуют снимкам; в измерении модель вращается с шагом 0.01 радиан на кадр. Учитываются CPU-рендер и ASCII-преобразование; загрузка OBJ, вывод в терминал и запись снимков исключены.

| Модель | Невырожденные треугольники | До, мс/кадр | После, мс/кадр |
| --- | ---: | ---: | ---: |
| Куб | 12 | 0.373 | 0.528 |
| Череп `part_0` | 31 016 | 7.014 | 7.587 |

7.587 мс соответствует примерно 132 FPS без терминального I/O и укладывается в CPU-бюджет 33.3 мс для целевых 30 FPS в этом окружении. Фактическая частота в терминале зависит также от его размера, шрифта, вывода и нагрузки системы.

## Воспроизведение

Модель остаётся локальной и исключена из Git; её экспорт содержит [исходную ссылку Sketchfab](https://sketchfab.com/models/1a9db900738d44298b0bc59f68123393). В состав репозитория входят только текстовые изображения результата рендера.

```sh
cargo run --release --example benchmark -- Skull.obj --object part_0 \
  --rotate-x 180 --columns 120 --rows 40 --frames 300 \
  --snapshot-dir docs/readability

cargo run --release -- Skull.obj --object part_0 --rotate-x 180
cargo run --release -- Skull.obj --object part_0 --rotate-x 180 --view depth
```

Чтобы сравнить режимы на одном ракурсе в просмотрщике, нажмите Space, затем переключайте `1`–`6`. Меняйте стрелками свет, `,`/`.` — контраст, `[`/`]` — gamma, `+`/`-` — масштаб. `0` возвращает параметры запуска. Изменение контраста/gamma не влияет на диагностические режимы.
